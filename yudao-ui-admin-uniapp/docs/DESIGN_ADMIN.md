## 1. 纠正项目定位

客户通过 `yudao-mall-uniapp` 买货，店主通过 `yudao-ui-admin-uniapp` 管理商品、订单和发货。两者复用 mall 服务器上的 Java、MySQL 和 Redis，分别使用会员接口与管理接口。

2026-11-14用户进一步确认移除电脑管理后台。运营能力集中建设在店主微信管理端，具体实现以移动端组件和手机交互组织；高级配置按必要性提供受权限控制的移动入口或维护流程。

| 角色 | 源码 | 接口 | 主要用途 |
| --- | --- | --- | --- |
| 客户 | `yudao-mall-uniapp` | `/app-api` | 浏览、购买、支付、查看订单 |
| 店主 | `yudao-ui-admin-uniapp` | `/admin-api` | 上架商品、改库存、发货、售后 |
| 业务服务 | `ruoyi-vue-pro` | Java接口 | 权限、库存、订单与资金规则 |

两个小程序分别构建和上传。店主管理端需要自己的小程序 AppID；当前客户小程序的 AppID 不写入店主管理端，以免两个独立代码包相互覆盖。

## 3. 手机界面与首版范围

底部固定四项：**工作台、商品、订单、我的**。每页只保留完成当前任务需要的操作。

| 页面 | 首屏内容 | 核心操作 |
| --- | --- | --- |
| 工作台 | 待发货、待售后、库存提醒、今日成交 | 去发货、处理售后、发布商品 |
| 商品 | 搜索、销售中与已下架分组、商品卡片 | 新建、编辑、上下架、调整库存 |
| 订单 | 搜索与状态分组、订单卡片 | 查看、发货、处理售后 |
| 我的 | 管理员身份、店铺设置、配送默认值、退出 | 必要设置与账号操作 |

经营数值必须来自有效接口。加载、零值、无权限和失败分别显示，不用示例数字代替真实待办。

### 3.1 发布商品

1. 从工作台或商品列表点击“发布商品”。
2. 从相册或拍照选图，填写名称、售价、库存和简短描述。
3. 普通商品默认单规格；需要时展开多规格和对应价格库存。
4. 分类、配送和运费复用有效店铺默认值，允许按需修改。
5. 保存成功返回商品列表，失败保留输入；提交期间防止重复创建。

简化表单时核对后端必填字段。品牌、简介、市场价、成本价等隐藏字段不能随意填零或伪造默认值，需先确定有效规则。已发布商品和历史订单继续按原业务规则处理。

### 3.2 发货与售后

待发货订单在列表中提供明显的发货操作。详情展示收货人、电话、地址、商品和实付金额，支持复制必要的收件信息。快递公司与单号确认后调用既有发货接口，成功再刷新订单状态，失败保留输入。

实际退款、退货与收货处理继续由后端校验和留痕。第一版不新增批量打单、营销活动、分销和独立聊天工作台。

客户咨询由微信官方小程序客服工具接待，沿用客户商城已改好的原生客服入口；店主管理小程序不另建一套聊天系统。

## 4. 登录与权限

店主首先使用现有管理账号登录，复用 `/admin-api/system/auth/*`、租户配置和角色权限。不能把客户的微信会员登录结果当作店主管理权限。

后续如需微信免输密码登录，应单独完成管理员与微信身份绑定，仍由后端确认管理员状态和每项操作权限。未绑定、停用或无权限的账号不能进入经营功能。手机号或会员身份本身不授予管理权限。

AppSecret、上传密钥和后端口令不写进小程序包或Git。现有管理账号口令由运营在登录时输入，不预填、不记录到配置中。

## 5. 本机开发与环境

新源码目录为 `D:\SouceFile\yuanmall\yudao-ui-admin-uniapp`，归属 yuanmall 总仓库。源码使用 `src/pages/`、`src/pages-mall/`、`src/components/` 和 `src/api/`，不直接编辑编译输出。

首次联调前，在 `env/.env.wechat.local` 填写实际店主管理小程序的 `VITE_WX_APPID`，并核对微信平台的合法域名。当前 `env/.env.wechat` 中 AppID 留空；不得使用上游示例 AppID代替。

从 yuanmall 根目录运行：

```powershell
# 仅首次安装或依赖变更时执行；本轮尚未安装
pnpm --dir yudao-ui-admin-uniapp install --frozen-lockfile

# 开发监听
pnpm --dir yudao-ui-admin-uniapp dev:mp-weixin

# 单独生成发布产物，不自动上传
pnpm --dir yudao-ui-admin-uniapp build:mp-weixin
```

| 用途 | 微信开发者工具目录 |
| --- | --- |
| 店主端开发 | `yudao-ui-admin-uniapp/dist/dev/mp-weixin` |
| 店主端发布前检查 | `yudao-ui-admin-uniapp/dist/build/mp-weixin` |
| 客户端开发 | `yudao-mall-uniapp/unpackage/dev/mp-weixin` |

两个项目的输出结构不同，实际启动后核对生成目录。微信持续编译进程按当前开发任务启动，减少本机同时运行的进程。

店主端使用 `https://mall.nexrur.ai/admin-api`。当前服务器对外域名可以切换开发/生产运行环境，因此独立小程序并不等于独立数据环境，联调前仍需确认实际连接的数据库。不得为迁移前端重新初始化数据库或另起一套商城Java服务。
